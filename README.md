# SheComfort

SheComfort is a menstrual wellness mobile application developed using .NET MAUI and C#.
The application aims to provide women with accessible menstrual health information, self-care guidance and a personal diary to record their experiences.

**Key Features**
**Home:** Provides quick access to the application's main features and personal diary.
**For First-Timers:** Offers educational information about menstrual changes across different life stages.
**Self-Care & Wellness:** Provides physical, mental, and nutritional wellness tips.
**My Diary:** Allows users to record, save, view, and delete personal diary entries.
